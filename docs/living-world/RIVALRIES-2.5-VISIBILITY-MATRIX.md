# Rivalries 2.5 Visibility and Abuse Matrix

| Case | Create receipt | Participant view | Involved-only view | Public/story view | Decision |
| --- | --- | --- | --- | --- | --- |
| Verified mutual settled action | yes | full safe history | safe history | only verified aggregate facts | eligible |
| Verified one-sided action | yes, bounded | full safe history | safe history | no tactical detail; conservative aggregate only | no fair-play award |
| Chat/passive observation | no | none | none | none | reject |
| Unparticipating target | no | none | none | none | reject |
| Same-account/self-alt pair | no | none | none | none | reject and audit reason |
| Blocked or muted viewer | no new effect | existing safe private view only | suppress relationship | suppress publication | presentation suppression |
| Moderated source/relationship | preserve source fact | suppressed/explanation | suppressed | suppressed | non-destructive suppression |
| Alliance/linked-account collusion | no progression | explanation if authorized | suppressed | suppressed | reject progression |
| Private scout/combat/stock/power/account/recon data | receipt may retain only safe metadata | omit private fields | omit private fields | never expose | sanitize |

All public projections are allow-listed from persisted facts. They never serialize raw source payloads or tactical/account data. Suppression changes visibility and future progression only; it does not rewrite or delete authoritative source receipts.
