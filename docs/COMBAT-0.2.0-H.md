# 0.2.0-H raid trophies

0.2.0-H keeps the G combat balance and starts the achievement/balance pass for the expanded raid system. The first slice gives the new raid forms public goals so players have a reason to try more than cash raids.

## Status

- Ruleset: `classic-og-v0.2-h` at version `0.2.0-H`.
- Combat model version: `0.2.0-H.1`.
- Default seed: `Game #008 - Raid Trophies`.
- Balance: inherited from 0.2.0-G for the first slice.

## First H slice

- Added a pinned H ruleset identity so new rounds can move forward while older F and G rounds stay pinned.
- Added public achievements for the expanded raid kit:
  - sending and landing drive-bys;
  - winning drug runs and drugging rival hoes;
  - stealing Low-Riders;
  - winning lure runs and recruiting rival crew.
- The achievement context now reads existing battle reports for drive-bys and special raid forms, so older reports from this combat model count without a schema migration.
- Seed, health, top bar, news and docs now identify the active work as 0.2.0-H.

## Next H work

- Tune drive-by, drug-run, ride-theft and lure-run rewards after testing the new achievement incentives.
- Add report callouts when a raid trophy unlocks.
- Add profile filters for earned, locked and combat-only achievements.
- Add a small balance simulation for special raid forms, similar to the cash raid simulator.
