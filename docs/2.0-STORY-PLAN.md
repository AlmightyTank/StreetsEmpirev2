# StreetsEmpire 2.0 Story Plan

## Product promise

**Every empire has a story. Build yours.** The 2.0 story slice connects existing systems through durable city memory rather than adding power creep. Turf, wars, operations, news, intel, profiles, careers, and onboarding share real settled actions as their source of truth.

## Shipped slice and thresholds

| Capability | Launch behavior | Thresholds and limits |
| --- | --- | --- |
| City memory | Settled takeovers, block wars, and operations emit idempotent `CityMemoryEvent` rows. Readers enforce `public` or `involved-only` visibility. | One row per source idempotency key. |
| Streets Daily | Public supported events become held `GameNews` drafts. An admin edits/publishes or rejects each draft; publishing creates participant Street Reports. | 20 events per generator call by default; requested limit clamped to 1–100; drafts are held 10 years ahead; `cityMemoryEventId` uniquely deduplicates retries. |
| Criminal operations | One `CORNER_TAKEOVER` prototype runs `INTEL → CREW_LOCK → READY → EXECUTING → REPORTED` with driver, enforcer, and intel seats. | 24-hour leader cooldown; 24-hour invite expiry; success chance is 50% plus 15 percentage points per additional distinct crew member; successful $1,500 pot is split across distinct crew. |
| Empire Legacy | Round close snapshots permanent season finishes, public city moments, and Daily covers into immutable account receipts. One owned receipt can be featured. | Cosmetic only. Legacy is not an input to fresh-round resources, economy, combat, or unlocks. |
| Black Book | Recon is projected into qualitative rumors with source provenance and expiry. Page load lazily removes stale rows. | One distinct source kind = `rumor`, two = `likely`, three = `confirmed`; repeating one kind does not increase confidence. Defense bands are `light` (<25 fit thugs), `guarded` (25–99), `heavy` (100+), or `unknown`; exact values remain in combat recon. |
| Career identity | Enforcer, Smuggler, Fixer, Business Boss, or Intelligence Broker adds a public title and optional contract-category lens. The lens can be disabled to show all contracts. | Seven-day switch cooldown. Cosmetic/presentation only; access, rewards, and game math stay equal. |
| Origin | Ruleset `classic-og-v1.9-c` adds four linear beats using real activity events: scout, build a business, resolve an encounter, choose a career. | Each one-time beat pays the same $1,000. The catalog is tested; the target 15-minute live playthrough still requires browser acceptance. |

## Rollout controls

There is **no `storyMemoryEnabled` runtime flag** in this implementation. The earlier design proposed one, but launch control currently consists of:

1. Apply the four additive migrations in order:
   - `20261020100000_empire_story_backbone`
   - `20261020110000_empire_legacy`
   - `20261020120000_black_book_intel`
   - `20261020130000_career_identity`
2. Pin a new round to `classic-og-v1.9-c` to enable the origin quest catalog. Older pinned rounds retain their existing ruleset.
3. Invoke the Streets Daily generator only in draft mode. There is no scheduler/CLI in this slice; `generateDailyDrafts` is an explicit service entry point and never publishes directly.
4. Admins gate all generated stories through the existing news approve/edit/reject flow.

Rollback is operational: stop invoking the Daily generator, stop creating rounds on 1.8-p, and hide/disable the new routes in deployment configuration if needed. The additive tables can remain in place. Do not roll back by deleting story rows during a live round.

## Verification commands

Run from the repository root in PowerShell. The placeholder URL is syntactically valid for schema and non-DB unit checks; DB integration suites remain skipped unless a real migrated database is available.

```powershell
$env:DATABASE_URL='postgresql://postgres:postgres@localhost:5432/streets'
$env:SESSION_SECRET='test-session-secret-at-least-32-chars'

npx prisma validate
npm run typecheck
npm test -- --run
npm run qa:turf
npx vitest run apps/server/src/services/__tests__/street-daily.service.test.ts
npx openspec validate empire-story-2-0 --strict
```

The Street Daily test is the draft-mode gate: it verifies one eligible event creates one held draft and a retry creates zero duplicates. It does not require or simulate publishing.

## Manual acceptance still required

- Apply migrations to a disposable dev database and start a round on `classic-og-v1.9-c`.
- Complete the four origin beats with a new account and record elapsed time; acceptance target is 15 minutes.
- Complete one takeover and one operation, then visually verify the turf memory banner, operations report, Daily admin draft, published participant report, Black Book links, public career marker, and Legacy gallery after round close.
